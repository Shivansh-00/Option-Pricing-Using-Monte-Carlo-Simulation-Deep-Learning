# 🚀 OptiQuant — One-Click Deploy Guide

## Option 1: Render (Recommended — 3 minutes)

### Step 1 — Create Render account
Sign up at https://render.com (free, no credit card for free tier).

### Step 2 — Connect GitHub
- Dashboard → **New +** → **Blueprint**
- Connect your GitHub account
- Select repo: `Shivansh-00/Option-Pricing-Using-Monte-Carlo-Simulation-Deep-Learning`
- Render auto-detects `render.yaml` ✅

### Step 3 — Set the 2 secrets
When Render asks for environment variables marked `sync: false`, paste:

| Key | Source |
|---|---|
| `DATABASE_URL` | Copy from your local `backend/.env` (Neon connection string) |
| `GROQ_API_KEY` | Copy from your local `backend/.env` (starts with `gsk_...`) |

(`JWT_SECRET` is auto-generated by Render.)

> 🔒 **Never commit real secrets.** Get them from your local `backend/.env` file or regenerate from Neon/Groq dashboards.

### Step 4 — Click "Apply"
- Render builds the Docker image (~5 min first time)
- Auto-deploys to `https://optiquant-backend.onrender.com`
- Frontend, API, RAG, models — all live at that URL

### Step 5 — Verify
```
https://<your-service>.onrender.com/         → Frontend
https://<your-service>.onrender.com/login.html
https://<your-service>.onrender.com/health   → {"status":"ok"}
https://<your-service>.onrender.com/docs     → Swagger UI
https://<your-service>.onrender.com/metrics  → Prometheus
```

Login with: `smoke` / `SmokeTest123!`

## Option 2: Local Docker Test (before pushing)

```bash
docker build -t optiquant .
docker run -p 8000:8000 \
  -e DATABASE_URL="<neon-url>" \
  -e GROQ_API_KEY="<groq-key>" \
  -e JWT_SECRET="$(openssl rand -hex 32)" \
  optiquant
```

Open: http://localhost:8000

## Option 3: Fly.io (alternative, also free)

```bash
flyctl launch --dockerfile Dockerfile --name optiquant
flyctl secrets set DATABASE_URL="..." GROQ_API_KEY="..." JWT_SECRET="$(openssl rand -hex 32)"
flyctl deploy
```

## Troubleshooting

**Build fails with "out of memory"** → Upgrade to `standard` plan (2GB) temporarily, or remove `torch` from requirements.

**Models not loading** → Check Render logs: `[loader] ✅ Loaded X models`. Models ship inside the image at `/app/backend/models/`.

**RAG returns empty** → Verify `GROQ_API_KEY` env var in Render dashboard.

**DB errors** → Confirm `DATABASE_URL` ends with `?sslmode=require` (Neon requires SSL).

**CORS errors** → Set `CORS_ORIGINS` env var to your frontend domain.
